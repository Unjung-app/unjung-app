4단계만 따라 하세요

무엇을 만들지는 내가 정하고, 코드는 AI가 씁니다. 설치할 프로그램은 없어요.

지킬 것 3가지 · 내 기능 폴더 안에서만 고치기 · 비밀번호·개인정보 넣지 않기 · 10분 막히면 대표에게

1열기

  • GitHub에 로그인 (계정이 없거나 초대를 못 받았으면 대표에게)
  • 처음: 앱 GitHub 페이지에서 초록색 Code → Codespaces → Create codespace on main (2~3분)
  • 다음부터: github.com/codespaces에서 내 것을 다시 열기. 새로 만들지 마세요.
  • 화면 아래 터미널 패널의 +를 눌러 새 터미널을 열고, 명령은 여기에 입력해요. ('앱 실행' 터미널은 그대로 두기)

오른쪽(또는 새 탭)에 앱 미리보기가 보이면 성공

2고르기

npm run work
  • 영문 이름을 입력하고, 기능 번호를 고릅니다.
  • 0번 = 내 아이디어로 새 기능 만들기

준비 끝!이 나오면 성공. 미리보기 홈의 "만드는 중이에요"에서 내 기능을 누르면 내 화면이에요.

3만들기

npm run ai
  1. 열린 ai-context.md 안을 한 번 클릭 → Ctrl+A → Ctrl+C
  2. AI 채팅(ChatGPT·Gemini 등)에 붙여넣기 → AI가 "준비됐어"
  3. 만들고 싶은 것을 한 번에 하나씩 말하기
  4. AI가 말한 파일(예: app/music/page.js)을 왼쪽 목록에서 열고 통째로 바꾸기 → 미리보기 확인

3~4번을 반복하며 완성해 가요. 채팅을 새로 열 때만 npm run ai를 다시 해요.

4올리기

npm run save
  • 무엇을 했는지 한 줄로 적기
  • 주소가 나오면 Ctrl+클릭 → 초록색 Create pull request

할 일 끝!이 나오거나 PR을 만들면 성공. 대표가 확인하고 합치면 실제 앱에 나와요.

작은 것이라도 될 때마다 올리세요. 끝날 때도 한 번 더.

필요할 때만 펼쳐 보세요

다른 사람과 같은 곳을 고쳐서 생긴 일이에요. 망가진 게 아니에요.

  1. 자동으로 열린 conflict-help.md를 전부 복사해서 AI에게 붙여넣기
  2. AI가 준 코드로 그 파일을 통째로 바꾸기
  3. 미리보기에서 내 기능과 다른 사람 기능이 둘 다 되는지 확인
  4. npm run save

AI가 "한쪽 코드를 지워야 한다"고 하면, 진행하기 전에 대표에게 물어보세요.

AI에게 잘 부탁하는 법
  • 화면에 무엇이 보이고, 무엇을 누르면 어떻게 되는지 말하기
  • 한 번에 하나씩 작게 쌓아 가기
예) 노래 제목을 입력하는 칸과 [신청] 버튼을 만들어 줘. 신청하면 아래 목록에 추가되게 해 줘.

잘 안 될 때:

[한 것] 신청 버튼을 눌렀어. [기대] 목록에 추가돼야 해. [실제] 아무 반응이 없어. [에러] (빨간 글자 전부, 없으면 "없음")
처음 한 번: 사전 점검
  • ☐ 학교 컴퓨터에서 GitHub 로그인이 된다 (인증용 휴대폰 준비)
  • ☐ npm run check가 모두 ✅
  • ☐ 학교 와이파이에서 AI 채팅이 대답한다

AI 서비스마다 나이 제한이 있어요(예: Claude.ai는 만 18세 이상). 내가 쓸 수 있는 서비스를 쓰세요.

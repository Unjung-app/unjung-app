4단계만 따라 하세요

무엇을 만들지는 내가 정하고, 코드는 AI(Copilot)가 씁니다. 설치할 프로그램은 없어요.

지킬 것 3가지 · 내 폴더 안에서만 고치기 · 비밀번호·개인정보 넣지 않기 · 10분 막히면 대표에게

1열기

  • GitHub에 로그인 (계정이 없거나 초대를 못 받았으면 대표에게)
  • 처음: 앱 GitHub 페이지에서 초록색 Code → Codespaces → Create codespace on main (3~5분)
  • 다음부터: github.com/codespaces에서 내 것을 다시 열기. 새로 만들지 마세요.
  • 화면 아래 터미널 패널의 +를 눌러 새 터미널을 열고, 명령은 여기에 입력해요. ('앱 실행' 터미널은 그대로 두기)

오른쪽(또는 새 탭)에 앱 미리보기가 보이면 성공. 처음엔 1분쯤 걸려요.

2고르기

npm run work
  • 영문 이름을 입력하고, 번호를 고릅니다. 무엇을 할지는 내가 정해요.
  • 0번 = 내 아이디어로 새 기능 만들기 (실험실에 생겨요)
  • 실험실 기능 = 친구 기능에 함께하거나 내 기능 이어 하기
  • 정식 기능 = 급식·시간표처럼 이미 앱에 있는 기능 고치기·개선하기

준비 끝!이 나오면 성공. 마지막에 나온 고칠 폴더를 기억해 두세요.

실험실 기능은 미리보기 아래 탭 전체 → 실험실 (베타)에서 볼 수 있어요.

3만들기 (Copilot)

  1. Ctrl+Alt+I 로 Copilot 채팅 열기 (처음이면 GitHub 로그인 허락)
  2. 채팅 입력칸 아래에서 Agent가 선택돼 있는지 확인
  3. 요청 양식으로 한 번에 자세히 부탁하기
    새 기능 /feature 시험 기간에 1학년이 쓰는 기능. 화면에 시험까지 남은 날짜와 과목 목록이 보이고, 과목을 누르면 공부 완료 체크가 돼. 정보는 내가 직접 입력.
    고치기 /improve src/features/meal/ — 지금은 오늘 급식만 크게 보여. 내일 급식도 바로 아래에 작게 보였으면 좋겠어.
  4. Copilot이 파일을 직접 고쳐요. 미리보기에서 확인하고 마음에 들면 Keep, 아니면 Undo
  5. Copilot이 명령을 실행해도 되냐고 물으면(npx tsc 등) Allow 또는 Continue

무료 Copilot은 한 달에 채팅 약 50번이에요. 짧게 여러 번보다 한 번에 자세히 부탁하세요.

4올리기

npm run save
  • 무엇을 했는지 한 줄로 적기
  • 주소가 나오면 Ctrl+클릭 → 초록색 Create pull request

할 일 끝!이 나오거나 PR을 만들면 성공. 대표가 확인하고 합치면 실제 앱에 나와요.

작은 것이라도 될 때마다 올리세요. 끝날 때도 한 번 더.

필요할 때만 펼쳐 보세요

네 가지를 넣으면 한 번에 잘 만들어요.

  • 누가 언제 쓰나 · 화면에 무엇이 보이나 · 누르면 어떻게 되나 · 어떤 정보를 쓰나
  • Copilot이 ①②③ 보기로 물어보면 번호로 답해도 돼요.

잘 안 될 때:

[한 것] 과목을 눌렀어. [기대] 체크 표시가 생겨야 해. [실제] 아무 반응이 없어. [오류] (빨간 글자 전부, 없으면 "없음")
"충돌"이 났다고 나오면

다른 사람과 같은 곳을 고쳐서 생긴 일이에요. 망가진 게 아니에요.

  1. 자동으로 열린 conflict-help.md를 Copilot 채팅에 끌어다 놓고 "이대로 충돌 해결해 줘"
  2. 미리보기에서 내 기능과 다른 사람 기능이 둘 다 되는지 확인
  3. npm run save

AI가 "한쪽 코드를 지워야 한다"고 하면, 진행하기 전에 대표에게 물어보세요.

다 만들었을 때 · 아이디어 올리기
  • 실험실 기능을 다 만들면 Copilot에게 "meta.json의 status를 ready로 바꿔 줘" → npm run save. 실험실에 완성 표시가 붙어요.
  • 이모지(✨)를 바꾸고 싶으면 "meta.json의 emoji를 🎵로 바꿔 줘"
  • 공용 부분(로그인·서버·데이터 저장)이 필요하면 PR 설명에 "○○가 필요해요"라고 적어 주세요. 대표가 도와줘요.
  • 아이디어만 남기고 싶으면 GitHub Issues → New issue → 💡 기능 아이디어

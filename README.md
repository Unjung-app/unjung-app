# 운중고 전용 앱 InCloud
전교생을 위한 학교 정보 통합 앱. 급식·시간표·공지·설문을 한 곳에서.
## 배포 주소
https://(vercel주소)
## 기술 스택
- Next.js (App Router) / TypeScript / Tailwind CSS
- Supabase (데이터베이스)
- Vercel (배포)
## 로컬 실행 방법
```
npm install
cp .env.example .env.local # 값은 대표에게 요청
npm run dev
```
브라우저에서 http://localhost:3000 접속
## 폴더 구조
- `app/` 페이지
- `components/` 공용 UI 부품
- `lib/` 데이터 처리 함수
- `docs/` 운영 문서
- `members/` 참여자 소개
